# Portfólio de Cauã

Projeto desenvolvido ao longo da unidade de Programação Front-End. O site apresenta informações acadêmicas, conhecimentos, projetos e um formulário de contato com envio real e modo de demonstração.

## Como executar

1. Baixe ou extraia esta pasta.
2. Abra o arquivo `index.html` em um navegador atualizado.
3. Para editar, abra a pasta em um editor de código, como Visual Studio Code.

Não é necessário instalar dependências.

## Arquivos

- `index.html`: estrutura e conteúdo da página.
- `style.css`: cores, organização visual e adaptação para telas menores.
- `script.js`: filtro dos projetos e validação do formulário.
- `imagens/`: ilustrações dos projetos em SVG.
- `documentacao/`: diagnóstico, testes, revisão e relatório técnico.

## Funcionalidades

- Menu com links para as seções da página.
- Filtro de projetos por tecnologia, com quantidade e aviso quando não há resultados.
- Formulário com validação de nome, e-mail, motivo, assunto condicional e mensagem.
- Contador de caracteres da mensagem.
- Conhecimentos em HTML, CSS e JavaScript, além de Java em nível iniciante, com introdução à POO.
- Envio real de mensagens pelo FormSubmit
- Modo de demonstração controlada de sucesso e falha para a apresentação.

## Atenção sobre o contato

O formulário usa o serviço FormSubmit para encaminhar mensagens. No primeiro envio, o serviço pode solicitar a confirmação do endereço por um e-mail de ativação. Até essa confirmação, o envio real pode não funcionar. A opção de demonstração serve apenas para testar sucesso e falha em sala e não envia mensagens.

## Documentação

Os arquivos da pasta `documentacao` precisam ser revisados após os testes no navegador e a revisão de um colega. Não marque testes ou evidências como concluídos sem executá-los.
